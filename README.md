# Portfólio convertido para o Modelo Sass

Este projeto usa a estrutura do seu `modelo-sass-main` como base:

- `css/style.scss` — estilos do portfólio convertidos para Sass
- `css/sass/_colors.scss` — biblioteca de cores
- `css/sass/_layout.scss` — containers e mixin `responsive`
- `css/sass/_spacing.scss` — espaçamentos utilitários
- `css/sass/_typography.scss` — tipografia base
- `js/script.js` — interações e animações
- `index.html` — estrutura do portfólio

O CSS compilado atual (`css/style.css`) foi mantido funcionalmente idêntico ao CSS original do portfólio, enquanto o `style.scss` foi reorganizado para usar a estrutura e os mixins da sua biblioteca Sass.
